# 게임플레이 진단 보고서 — 왜 FM 같은 요소를 넣었는데 재미가 없는가

> 작성 기준 커밋: `claude/relaxed-lamport-hhnaqa` (046f908). 인용한 file:line은 이 시점 기준이며, 구현 중 코드가 밀리면 함수명으로 다시 찾을 것.

## 요약 (TL;DR)

이 게임은 FM의 **표면적 형태**(스쿼드/전술/훈련/이적/재정/언론/승강제/컵)는 갖췄지만, FM을 재미있게 만드는 **피드백 루프가 전부 끊겨 있다**. 구체적으로:

1. **관리 레버가 경기 결과에 닿지 않는다** — 컨디션·폼·부상이 죽은 코드라서 로테이션/육성/맨매니지먼트가 승부에 0% 반영. 유일하게 살아있는 모랄도 최대 ±5%.
2. **판돈이 없다** — 목표도, 경질도, 상금도, 파산도 없어서 이기든 지든 게임 상태가 거의 같다.
3. **세계가 정적이다** — AI는 이적도 안 하고, 선수는 은퇴도 안 하고, 유스도 안 나온다. 내 클릭 말고는 아무것도 변하지 않는다.
4. **피드백이 보이지 않는다** — 훈련 성장, 팀토크 효과, 전술 변경 효과가 전부 무음. 플레이어가 "내 선택이 통했다"를 학습할 방법이 없다.

수정 지시서는 3단계로 분리했다: [P0 죽은 시스템 소생](./01-p0-tasks.md) → [P1 판돈과 보상](./02-p1-tasks.md) → [P2 살아있는 세계 + 페이싱](./03-p2-tasks.md).

## 1. 죽은 시스템 — 타입·시뮬레이션·UI까지 있는데 아무도 값을 쓰지 않는다

시뮬레이션은 선수별 유효 능력치를 `ovr × developmentFactor(p)`로 계산하고, `developmentFactor`는 컨디션×폼×모랄이다 (`src/lib/sports/common/simutil.ts:35-40`):

| 항 | 공식 | 이론상 범위 | **실제** |
|---|---|---|---|
| condition | `0.8 + condition/100 × 0.2` | 0.80–1.00 (±20%) | 생성 시 88–100으로 고정(`common/generate.ts:70`), **이후 어디서도 변경 안 됨** → 상수 |
| form | `1 + form × 0.018` | ±9% | `form: 0`으로 생성(`generate.ts:71`) 후 **영원히 0** → 항상 1.0 |
| morale | `1 + (morale−50)/50 × 0.05` | ±5% | 유일하게 살아있음. 단, 언론 답변(±4)과 팀토크(+5/+2/−1)만 움직임 |

코드 주석은 "~1.45× 관리 스윙"을 약속하지만(`simutil.ts:31`), 실제로는 **모랄 ±5%가 전부**다. 결과적으로 승부는 `raw OVR × 세그먼트당 ±18% 난수(performanceMultiplier, simutil.ts:23-25)`로만 결정된다.

구체적 사망 목록:

- **`player.condition`** — 쓰기 지점 0곳. 피로 없음, 회복 없음, 로테이션 무의미. 대시보드의 "선발 체력 저하" 경고(`selectors/dashboard.ts:10` `LOW_CONDITION_THRESHOLD = 60`, `:113`)는 **절대 발화할 수 없다**.
- **`player.form`(수치)** — 쓰기 지점 0곳. `recentForm[]` 이력은 매 경기 갱신되지만(`engine/matchFlow.ts:25-42`) 표시 전용이며 수치 폼에 연결 안 됨.
- **`injuredUntilDay`** — 할당 지점 0곳. 축구 sim은 부상 이벤트를 굴리지만(`soccer/sim.ts` 부상 롤 `bool(0.1×scale)`) 아무 효과 없음. 훈련 페이지 부상자 목록과 대시보드 부상 경고(`dashboard.ts:100`)는 **영구 공백 UI**.
- **`contractUntil`** — 월드 생성 후 검사 지점 0곳. 만료/재계약/FA 없음.
- **모랄** — 승패/연승/연패에 무반응. 연패해도 유저가 부정적 언론 답변을 고르지 않는 한 모랄이 안 떨어진다.
- **퇴장(레드카드)** — 이벤트만 생성되고 팀 전력에 0% 반영 (10명 축구 = 11명 축구).

**설계적 결론:** FM의 핵심 주간 긴장 — "누굴 쉬게 할까, 폼 좋은 선수를 쓸까, 부상 리스크를 감수할까" — 가 이 게임에는 **원천적으로 존재할 수 없다**. UI는 그 긴장이 있는 것처럼 보여주므로, 플레이어는 몇 경기 안에 "이 숫자들 아무 의미 없네"를 학습하고 흥미를 잃는다. **가짜 심도는 심도가 없는 것보다 나쁘다.**

## 2. 판돈 없음 — 이기든 지든 게임 상태가 같다

- **이사회/시즌 목표/경질 없음.** `Manager` 타입은 `{name, sportId, clubId, reputation}`뿐. 감독 평판(`applyManagerRep`, `matchFlow.ts:53-59`)은 이적 협상 배율(`gameStore.ts:47-50`)과 주간 수입에만 쓰이고, 성공/실패 조건이 없다. **꼴찌를 해도 아무 일도 일어나지 않는다.**
- **재정이 성적과 무관.** 주간 수입 = `reputation × 1800 + wageBill × 0.15` (`engine/season.ts:69`). 우승해도 강등돼도 수입이 같다. 입장 수입/상금/승격 보너스/스폰서 전무. 잔고가 마이너스여도 경고 배지 하나뿐, `wageBudget`도 미집행 — 재정은 **장식용 게이지**다.
- **기록이 남지 않는다.** 우승하면 `championId`가 계산되지만(`engine/competition.ts`) `rolloverSeason`이 대회를 새로 만들면서 폐기. 역대 우승/득점왕/MVP/커리어 통계/트로피 룸 전무. **여러 시즌을 플레이할 이유가 축적되지 않는다.**

**설계적 결론:** 게임의 재미는 "결과가 달라지는 선택"에서 나온다. 성공과 실패가 같은 상태로 수렴하면 선택의 무게가 0이 된다.

## 3. 정적인 세계 — 내 클릭 말고는 아무것도 변하지 않는다

- AI 클럽은 시즌 내내 **동결**: 이적 없음, 내 선수에 대한 영입 제안 없음, 이적창 개념 없음(언제나 매매 가능).
- 롤오버 시 선수는 늙기만 한다(`growth.ts:31-60`): **은퇴 없음, 유스/리젠 없음** → 리그 전체 능력치가 시즌마다 단조 감소. 오래 할수록 세계가 시들어간다.
- 언론은 W/D/L별 **동일한 3문항**이 매 경기 반복(`engine/press.ts:6-41`).

**설계적 결론:** FM의 서사("라이벌이 내 에이스를 노린다", "유스에서 보석이 나왔다", "노장이 은퇴했다")를 만들 재료가 없다.

## 4. 페이싱과 피드백 — 선택은 적고, 한 결과는 안 보인다

- 시즌 = 8클럽 더블 라운드로빈 **14경기**. 대시보드 "계속" 1클릭이 경기 사이 ~7일을 무음으로 스킵(`engine/season.ts:91-116`) → 시즌 전체가 사실상 **"계속 → 경기 → 계속 → 경기" 14회 반복**.
- 훈련 = 팀 단위 포커스 토글 1개. 주간 성장(`growth.ts:62-77`, 주당 속성 +0.04~0.22)은 **완전 무음** — 델타 표시도, "성장했다" 뉴스도 없다.
- 경기 중: 팀토크는 숨은 모랄 델타만 적용되고 화면 확인 불가. 전술 변경은 카운터 정수만 증가. **개입 → 가시적 결과 연결 0**.
- 경기 후: 평점 상위 3명만 노출. 전체 스쿼드 평점 타일은 만들어놓고 `className="hidden"` 처리(`components/MatchViewer.tsx:340, 433, 451`). MOTM 없음.
- 농구는 지수 1.05(거의 선형) + 쿼터당 uniform(0.8,1.2)이 4쿼터 평균화되며 **이변이 거의 없는** 가장 예측 가능한 종목.

## 6. 참고 — 종목별 시뮬 공식 요약 (밸런스 조정 시 기준값)

| 종목 | 전력→득점 | 지수/스케일 | 경기 내 분산 | 홈 어드밴티지 |
|---|---|---|---|---|
| 축구 | `xg = 1.35×(atk/def)^1.4` → Poisson | 1.4 (가장 가파름 → 이변은 저득점 Poisson이 공급) | 세그먼트당 `clamp(gaussian(1,0.09), 0.82, 1.18)` | 홈 xG ×1.12 / 원정 ×0.95 |
| 농구 | 쿼터당 `26×(off/def)^1.05` | 1.05 (거의 선형 → **가장 예측 가능**) | 쿼터당 uniform(0.8,1.2) | ±0.6점/쿼터 |
| 야구 | 하프이닝 `λ = 0.48×(bat/pitch)^1.15` → Poisson | 1.15 | performanceMultiplier | 타격 +1.5, λ +0.03 |
| 배구 | 랠리 `1/(1+e^(−(H−A)/8))`, 클램프 [0.12,0.88] | logistic/8 | 세트당 클러치 `gaussian(0,2.5)` | 전력 +2, 서브 +0.025 |
| 피클볼 | 랠리 logistic/7, 클램프 [0.1,0.9] | logistic/7 | 게임당 클러치 `gaussian(0,2.5)` | 전력 +1.5, 서브 엣지 +0.04 |

전술은 **축구에만** 존재(`soccer/tactics.ts`: mentality ±12%/−8%, tempo ±12%, pressing → 상대 xG −6%/+3%, width → 이벤트 플레이버). 나머지 4종목은 전술 다이얼이 시뮬에 연결돼 있지 않다.
